Live plugin

The repo's own code.js runs here against a small figma stub, and ui.html runs in a sandboxed iframe (null origin, as in Figma) with the fallback palette injected the way showUI({ themeColors: true }) does. Plugin runs one of the examples/ folders instead (?plugin=examples/rename-layers in the address does the same). The stub is a stand-in, not Figma: a few fake layers, one font per text layer, the same 1×1 PNG from every export and three colour variables, so a plugin that runs here can still fail in Figma. Saved sizes go to this browser's localStorage, per plugin. Add ?config={"snapWidths":[300,400]} to the address to try a data-kit-config override.
